# Валлетта · Город за камнем

Русский мобильный аудиогид для прогулки вдвоём30октября2026:13остановок, персональный маршрут, GPS по отдельному разрешению, картаOpenStreetMap,13MP3 иPDF90×160мм.

React19 + Vite8 + TypeScript7. Backend использует реальный BX1.1.1 (`@dahura/bx`), Elysia Fetch handler и Node22 adapter для Vercel. Публичные процедуры: `guide.get`, `photo.explain`, `photo.confirm`. Проверенный каталог встроен в серверную сборку; при недоступности API сайт загружает статическую копию путеводителя. Личные точки и порядок остаются на устройстве.

## Запуск

Требуется Node22.12+ (22.x), npm, для генерации аудио — Python3 иFFmpeg.

```sh
npm ci
npm run dev
```

Отдельный терминал дляBX API:

```sh
envhub use impresme -- npm run dev:api
```

API слушает127.0.0.1:8788; Vite5173 проксирует `/api/bx`, сохраняя исходный Host. Для фотогида требуется серверный `OPENAI_API_KEY`, для видимости компонента — явный `VITE_PHOTO_GUIDE_ENABLED=true` при запуске/сборке. Последний флаг не является секретом. Ключи не попадают в клиентскую сборку и не нужны для обычного чтения/аудио.

`npm run build` собирает BX runtime, проверяет TypeScript и создаёт сайт в`dist`. Postinstall также создаёт необходимый `.bx/server.mjs`. PublishedBX1.1.1 содержит ESM/Bun особенности: Node adapter исключает CLI-only экспорты и явно запрещает неиспользуемый BunSQLite. Приложение не использует базу данных. Текущие query/mutation пути проверены настоящими HTTP-запросами, а не mock-ответами.

## Материалы

- `public/data/guide.json` — тексты, координаты, практика, источники и атрибуция фото.
- `public/data/route.geojson` и`public/maps` — исходный авторский пешеходный маршрут и карты.
- `public/audio` —13финальных MP3; `public/data/audio-manifest.json` содержит длительности и хеши.
- `public/downloads/valletta-audioguide-ru.pdf` —24страницы90×160мм с картами и рассказами.

## Голос

Использован уже существующий сгенерированный русскоязычный бас-баритон ElevenLabs **Halloween Velvet C selected**, модель **eleven_multilingual_v2**. Это не имитация известного человека. Новый голос «Брат Лоренцо» отложен из-за занятых голосовых слотов; ни один голос не удалён и новый слот не куплен. Все13треков читают дословно финальный `stop.narration`; хеши совпадают. Генератор: `scripts/elevenlabs_audio.py`.

## Фотогид

Камера/файл → локальный предпросмотр и сжатие с удалениемEXIF → явная кнопка отправки → реальное распознаваниеOpenAI **gpt-5.4-mini**. Положение передаётся только после отдельного согласия и не доказывает место. Кандидат подтверждается человеком; история и ссылки берутся из проверенного каталога. Для неизвестного снимка гид честно просит другой ракурс/табличку. Текст в фотографии не является инструкцией или историческим источником.

Сайт не хранит фотографии и не пишет тело запроса в лог. Есть ограничения1МБ/1600px, проверка сигнатуры и декодирования, строгий origin, таймаут, отмена и базовые лимитыIP/экземпляра. Лимиты экземпляра не являются глобальным долговечным потолком расходов на serverless-платформе. OpenAI получает изображение по явно инициированному запросу, с `store:false`.
